# BookReader

Audio de resúmenes de libros: sube, guarda y escucha tus resúmenes desde el navegador.

## Uso

```bash
npm install
npm start   # http://localhost:3000
```

Los audios (mp3, m4a, wav, ogg, aac, flac) y los metadatos se guardan en `data/` (ignorado por git).
Puerto configurable con `PORT`.
